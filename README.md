# 🏠 わが家の家計簿アプリ

ブラウザで動く家族向けの家計管理アプリです。インストール不要・データはブラウザに保存されます。

## 📂 ファイル構成

```
index.html       ← アプリ本体（これをブラウザで開く）
css/style.css    ← スタイルシート
js/categories.js ← カテゴリ定義
js/storage.js    ← データ管理（localStorage）
js/app.js        ← メインロジック・UI
```

## 🚀 使い方

1. `index.html` をブラウザで開く（またはWebサーバーで配信）
2. 初回起動時にサンプルデータが入ります
3. ボトムナビゲーションで各機能を切り替え

## 📱 画面一覧

| タブ | 機能 |
|------|------|
| 🏠 ダッシュボード | 月次収支サマリー・固定費チェック・犬の通院費グラフ |
| 💚 収入入力 | 7種類の収入カテゴリで登録 |
| ❤️ 支出入力 | 固定費・変動費・特別積立の3グループで登録 |
| 📅 履歴 | 当月の取引一覧・削除 |
| 📊 レポート | 収支推移グラフ・支出内訳・カテゴリ別集計 |
| 🏦 口座管理 | 5口座の残高管理 |

## 💰 収入カテゴリ（7種）

| 大項目 | 中項目 |
|--------|--------|
| 夫・給与 | 夫：本給（固定分）／夫：変動給（残業・シフト） |
| 私・事業 | 私：FC教室利益／私：動画編集 |
| 私・給与/在宅 | 私：在宅ワーク（時給）／私：アルバイトA／私：アルバイトB |

## 💸 支出カテゴリ（16種）

### 固定費
- 住宅ローン、電気代（オール電化）、水道代、スマホ代、ペット保険料、各種保険

### 変動費・生活費
- 犬：動物病院、犬：フード・消耗品、娘：教育・習い事、娘：衣服・イベント、医療費、お小遣い、予備費

### 特別支出積立
- 税金積立、年払い保険料積立、車検・メンテナンス積立

## 🎯 2つの特別ダッシュボード

### ① 収入と固定費の相殺チェック
- **夫の本給** vs **固定費合計** をゲージで可視化
- プラスなら精神的安定ゾーン 🟢

### ② 犬の通院費推移（過去12ヶ月）
- 月別棒グラフ（金額により自動で色分け）
- 年間累計・月平均を表示
- 次年度の予算立案に活用

## 📤 データ管理

- **CSVエクスポート**：設定ボタン → CSVエクスポート（Excel/Sheets対応のBOM付きUTF-8）
- **バックアップ**：エクスポートしたCSVを保存してください
- データはブラウザのlocalStorageに保存されます

## 💡 FPアドバイス（アプリ活用のコツ）

> 特別支出積立（税金・保険・車検）を毎月「特別積立口座への移動」として記録すると、
> 月末収支が黒字に見えてモチベーション維持につながります！

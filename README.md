# 公文式教室 Instagram運用会社

社長（あなた）の指示のもと、AIエージェントの社員がリサーチ、投稿作成、効果測定、Threads投稿の作成を分担して行います。
組織とルールは [CLAUDE.md](CLAUDE.md) を参照してください。

## はじめに社長がやること
1. `company/profile.md` の【要確認】を埋める（または、Claudeに聞かれたら答える）
2. 公文本部のSNS・広告ルールを `company/guidelines/kumon-official/` に入れる
3. 投稿後、インサイトの数値を `work/analytics/insights.csv` に手入力する

## 使い方
- 週次の運用：`/weekly`
- 個別の依頼の例：「researcherで冬休み前のネタを調べて」「analystで今週を振り返って」

CLAUDE.md の「標準ワークフロー（週次）」に従って、今週の運用サイクルを進めてください。$ARGUMENTS

- 各ステップは、該当するサブエージェント（analyst → researcher → ig-creator → threads-writer → compliance）に依頼してください。
- 各担当の報告に「社長への確認事項」があれば、次に進む前に AskUserQuestion で社長に確認してください。
- リサーチの後は、ネタを社長に選んでもらうまで制作に進まないでください。
- 最後に、審査結果をつけた投稿案の一覧を社長に提出し、承認を得てください。承認されたものだけ status を approved にします。
